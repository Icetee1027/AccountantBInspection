# 會計師考試選擇題練習系統

一個專為會計師考試設計的選擇題練習網頁應用程式，提供練習、考試、歷史紀錄和錯題複習等功能。

## 功能特色

### 📚 練習模式
- 立即查看答案，適合學習模式
- 支援多章節選擇
- 隨機出題，避免重複
- 鍵盤快捷鍵操作（1-4 選擇答案，Enter 下一題）

### ✍️ 考試模式
- 完成作答後統一查看結果
- 可選擇題目數量（10/20/30/40/50 題）
- 支援多章節組合考試
- 自動記錄考試結果到歷史紀錄
- 自動收集錯題到錯題本

### 📊 歷史紀錄
- 查看所有過往考試結果
- 顯示分數、答對/答錯數量
- 篩選功能（全部/有錯題）
- 查看詳細答題情況

### 🔍 錯題複習
- 自動收集考試中答錯的題目
- 專注複習弱點章節
- 提升學習效率

## 快速開始

### 方法一：直接開啟（最簡單）

1. 確保所有檔案都在同一個資料夾中
2. 雙擊開啟 `index.html` 檔案
3. 開始使用！

### 方法二：使用本地伺服器（推薦）

#### 使用 Python（如果已安裝）

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

然後在瀏覽器開啟：`http://localhost:8000`

#### 使用 Node.js（如果已安裝）

```bash
# 安裝 http-server（只需安裝一次）
npm install -g http-server

# 啟動伺服器
http-server -p 8000
```

然後在瀏覽器開啟：`http://localhost:8000`

#### 使用 VS Code Live Server

1. 在 VS Code 中安裝 "Live Server" 擴充功能
2. 右鍵點擊 `index.html`
3. 選擇 "Open with Live Server"

## 使用說明

### 練習模式

1. 從首頁點擊「練習」按鈕
2. 選擇一個或多個章節（可多選）
3. 開始練習，選擇答案後立即顯示正確答案
4. 使用鍵盤快捷鍵：
   - `1-4`：選擇答案選項
   - `Enter`：下一題（顯示答案後）

### 考試模式

1. 從首頁點擊「考試」按鈕
2. 選擇一個或多個章節（可多選）
3. 選擇題目數量（10/20/30/40/50 題）
4. 開始作答，可以隨時返回修改答案
5. 完成所有題目後點擊「完成作答」
6. 查看分數和詳細結果
7. 答錯的題目會自動加入錯題本

### 查看歷史紀錄

1. 從首頁點擊「歷史紀錄」按鈕
2. 查看所有考試記錄
3. 使用篩選功能查看特定記錄
4. 點擊「查看詳情」查看完整答題情況

### 錯題複習

1. 從歷史紀錄頁面進入錯題複習
2. 複習所有答錯過的題目
3. 加強弱點章節的練習

## 資料儲存

- 所有資料都儲存在瀏覽器的 **localStorage** 中
- 歷史紀錄和錯題本會自動保存
- 清除瀏覽器資料會刪除所有記錄

## 技術規格

- **純前端應用**：無需後端伺服器
- **響應式設計**：支援桌面和行動裝置
- **本地儲存**：使用 localStorage 保存資料
- **鍵盤快捷鍵**：提升操作效率

## 注意事項

1. 請確保 `questions_by_chapter.json` 檔案存在且格式正確
2. 建議使用現代瀏覽器（Chrome、Firefox、Safari、Edge）
3. 清除瀏覽器快取可能會影響已保存的歷史紀錄
4. 不同瀏覽器之間的資料不會同步

## 題目資料格式

題目資料儲存在 `questions_by_chapter.json` 中，格式如下：

```json
[
  {
    "chapter": 1,
    "questions": [
      {
        "id": 1,
        "question": "題目內容",
        "options": {
          "1": "選項一",
          "2": "選項二",
          "3": "選項三",
          "4": "選項四"
        },
        "answer": 1
      }
    ]
  }
]
```
